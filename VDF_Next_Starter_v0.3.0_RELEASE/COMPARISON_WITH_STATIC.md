# Comparison with Static VDF 6.0

## Preserved
- VDF 6.0 `rules.json` remains the canonical built-in fallback.
- Six information types, image/shape judgment, cards A–F and six-line prompt assembly are preserved.
- Layout selection remains a professor decision.

## Added by VDF Next
- DOCX/HWPX lecture-note import.
- Provider-independent Prompt Bridge.
- 4-step guided workflow.
- Engine ZIP Registry with IndexedDB persistence.
- Engine activation separated from registration.
- Engine ZIP download/export, including Built-in 6.0.
- Package-driven Regression Browser and Golden comparison.
- Common Tooltip Portal and focus management.

## Governance rule
UI, workflow, accessibility, registry and regression tooling are application-layer concerns. They do not silently change VDF canonical decision rules.
