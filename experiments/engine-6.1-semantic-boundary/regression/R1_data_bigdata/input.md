# R1 — 데이터와 빅데이터

## Scope/context
- 학습목표: 데이터와 정보의 차이, 빅데이터 정의와 5V, 데이터 유형, 데이터→가치
- 마음열기: 오늘 하루 몇 개의 데이터를 만들었는가?

## 본문
### 데이터 생성
우리는 데이터를 만들면서 살아간다. 하지만 데이터가 많다고 자동으로 가치가 되는 것은 아니다. 데이터는 목적에 맞게 정리·분석될 때 정보와 가치로 연결된다.

### Data ≠ Information
데이터는 사실과 기록, 정보는 목적에 따라 의미를 부여한 결과이다.

### 데이터 활용 흐름
DATA(사실·기록) → INFORMATION(의미 있는 정보) → INSIGHT(무엇이 일어나는가) → DECISION / VALUE(무엇을 할 것인가)

### 빅데이터 정의
단순히 아주 큰 데이터가 아니라 기존 방식만으로 효율적으로 다루기 어려운 데이터. 규모·다양성·속도·신뢰성·가치를 함께 본다.

### Big Data 5V
Volume 규모 / Variety 다양성 / Velocity 속도 / Veracity 신뢰성 / Value 가치

### 5V 구조화
3V: 다루기 어렵게 만드는 특성 — Volume, Variety, Velocity
2V: 활용 가치를 좌우하는 특성 — Veracity, Value

### 기사 Point
빅데이터의 기본 5V는 Volume, Variety, Velocity, Veracity, Value이다. 확장 분류도 있으나 본 강의의 Core는 5V이다.

### 데이터 유형
정형 / 반정형 / 비정형

### 적용하기 — 온라인 쇼핑몰 데이터
구매내역, 상품정보 JSON, 상품평, 상담 녹음, 배송 위치기록은 어떤 유형인가?

### 적용하기 해설 / 결론
구매내역=정형, 상품정보 JSON=반정형, 상품평·상담 녹음=비정형, 배송 위치는 구조에 따라 달라질 수 있다. 같은 서비스 안에서도 여러 유형의 데이터가 함께 생성된다. 데이터의 가치는 목적·품질·활용 방법에 따라 달라진다.

### 오개념 바로잡기
빅데이터=무조건 큰 데이터, 비정형 데이터가 항상 더 가치 있다, 데이터가 많으면 분석도 더 정확하다는 생각은 틀리기 쉽다. 가치는 목적·품질·활용 방법에 따라 달라진다.
