# VDF 6.0 Ablation Test Plan

## 목적
복합 Candidate에서 어떤 변경이 실제 개선/악화를 만들었는지 분리한다. VDF 6.0 Reference는 수정하지 않는다.

## 후보
- **S · Scope-only**: 본문 vs 보조 학습활동 역할 구분만 변경.
- **B · Block-only**: 인접 사례의 의미 단위 병합 원칙만 변경.
- **G · Gate-only**: 구체 사물이 학습정보의 중심인지 확인하는 질문만 변경.

## 고정 조건
동일 ChatGPT 모델 · 임시채팅 · **Instant** · 동일 CASE-01~03 · 후보별 각 1회. 한 실행 안에서 후보를 섞지 않는다.

## 판정 질문
1. **S**: CASE-01의 학습코너 승격이 줄면서 6.0의 커피/교통 등 유효 시각 후보는 유지되는가?
2. **B**: CASE-02의 과분할이 줄면서 CASE-01/02의 유효 이미지 후보가 사라지지 않는가?
3. **G**: 보조 사례·애매한 사물 이미지는 줄면서 캡슐 커피머신/클립 변형 같은 핵심 시각 후보는 유지되는가?

## 승인 규칙
- 한 후보가 한 문제를 개선하면서 다른 보호 케이스를 악화시키면 **폐기**한다.
- block 수 자체를 정답으로 삼지 않는다.
- 규칙 추가 없이, 효과가 입증된 후보만 다음 통합 검토 대상으로 올린다.
- 효과가 불분명하면 6.0을 유지한다.
